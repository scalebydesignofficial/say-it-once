# Facebook posts

Longer, more conversational posts for a Facebook page or group.

## Where it goes
`facebook-posts.md`, all posts in one file, separated by `---`.

## Shape
```
## Post 1: working title
Where: page / group
Post:
(the post)
First comment: optional, a link or a follow-up question
```

## Rules
- 150 to 300 words. Facebook readers will go longer than Instagram readers. Tell it like you would to a friend across the table.
- Open with a line that sounds like a real person talking, not a headline.
- End with one specific question that invites a real answer, then (only if it fits) the one next step from `brand/offer.md`. Never stack two asks.
- For group posts, make the question the point of the post. Give the group something to answer.
- Include 2 community-question posts (short, 40 to 80 words, just a question and one line of context).
- No hashtags. No "link in bio." Put any link in the first comment line, written as a plain sentence.
- Different angle per post. Nothing invented.
