# Substack notes

Short standalone posts, 40 to 150 words, that sound like a thought the person just had.

## Where it goes
`notes.md`, all notes in one file, separated by `---`.

## Rules
- Each note has a different angle and a different shape: one blunt statement, one question, one tiny story from the source, one permission slip, one list of three, and so on.
- First line stands alone. Short paragraphs. No hashtags.
- Only some notes carry a next step. Notes are mostly reach and warm. Add one next step to about one in three.
- No headings, no bullets unless it is a true list.
