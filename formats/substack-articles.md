# Substack articles

Full pieces for a Substack newsletter, 700 to 1,100 words.

## Where it goes
`substack-articles/NN-<slug>.md`

## File shape
```
# Title (plain, specific, under 70 characters)
Subtitle: one line that promises something real

(body)

(closing with the one next step)
```

## Rules
- Open with a scene, a belief, or a plain statement. Never with "In this article" or a definition.
- Use short subheads only if they help, written as plain sentences, not Title Case.
- Teach from the source. One main idea per article, with the supporting points from the teaching. Do not pad.
- Same voice as everything else. This is long form, so there is room for a story that really is in the source, and room to let a thought breathe.
- End with one next step. No summary paragraph that repeats what you said.
- Each article takes a different angle on the source.
