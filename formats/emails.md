# Emails

Plain-text emails to the person's list.

## Where it goes
`emails.md`, all emails in one file, separated by `---`.

## Shape
```
## Email 1: working title
**Subject:** under 60 characters
**Preview:** under 90 characters, adds to the subject
(body, 150 to 300 words)
(one next step, as a plain sentence or one link line)
P.S. optional
```

## Rules
- Reads like a note from a friend. Greeting is just their first name merge tag if the person uses one in `brand/voice.md`, otherwise "Hey".
- One idea. One next step. Short paragraphs.
- Subject lines are specific and curious, not clickbait. No ALL CAPS, no emoji, no fake "Re:".
- Mix: a teaching email, a story email, a belief-challenge email, a permission email, a soft invite email.
- Never promise results. Never invent urgency or scarcity. Only mention deadlines the person gave you.
- Links and keywords come from `brand/offer.md`. If a link is missing, write the next step without a link and add it to the review file under placeholders. Never leave bracket placeholders in a piece.
