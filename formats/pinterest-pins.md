# Pinterest pins

Titles and descriptions for pins. People search Pinterest like a search engine, so the words matter more than the voice. The picture is a quote graphic or a carousel slide that already exists.

## Where it goes
`pinterest-pins.md`, all pins in one file, separated by `---`.

## Shape
```
## Pin 1: working title
Image: the file to pin, for example quote-graphics/quote-03.png or carousels/01-name/slide-01.png
Title: 100 characters or fewer
Description: 150 to 400 characters
Board: a suggested board name
Link: where the pin points, in the exact wording from brand/offer.md
```

## Rules
- Title: lead with the words a woman would type into the search bar ("how to stop people pleasing as a Christian woman"), then make it worth a click. Plain, specific, no clickbait and no promises of results.
- Description: write 2 or 3 sentences that say what the pin teaches and who it is for. Work in 2 or 3 natural search phrases. Never stuff them. No hashtag lists.
- Pick the image that fits: a quote graphic for a feeling or a truth, a carousel cover for a teaching. Name a real file that exists in the pack. Portrait images work best on Pinterest.
- Suggest 3 to 5 board names across the whole set, and reuse them so boards fill up.
- The link is the one next step from `brand/offer.md`. A keyword like "comment HOUSE" does not work on Pinterest, so use the join link instead and never invent a link.
- Every pin has its own angle and its own title. Nothing invented, no results promised.
- Make 4 to 8 pins per source.
