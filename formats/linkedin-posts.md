# LinkedIn posts

Text posts and document (carousel) posts for the person's LinkedIn profile or page.

## Where it goes
`linkedin-posts.md`, all posts in one file, separated by `---`.

## Shape
```
## Post 1: working title
Type: text / document
Document: (only for a document post) the carousel folder to upload, for example carousels/01-name/carousel.pdf
Post:
(the post)
First comment: optional, a link or a follow-up question
```

## Rules
- 120 to 250 words. First line is a hook that works before the "see more" cut, 90 characters or fewer, and it is not a headline.
- Short paragraphs, one or two lines each. White space between them.
- Professional but still the person's real voice. A little less slang than Instagram, never stiff.
- Write for someone scrolling at work: one clear idea, one clear takeaway they can use.
- Make 1 in 3 a document post: the person uploads the carousel's `carousel.pdf` (made automatically with every carousel) and the post text introduces it in 40 to 80 words.
- End with one specific question, then (only if it fits) the one next step from `brand/offer.md`. Never stack two asks.
- At most 3 hashtags, at the very end, only if `brand/profile.md` says they use hashtags. Links go in the first comment, written as a plain sentence.
- Do not invent a story, a result, or a statistic. If the source has none, build the post from the teaching.
- Different angle per post.
