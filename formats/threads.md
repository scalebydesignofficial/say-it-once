# Threads

Written for Threads, and usable on X. A thread is 4 to 8 short posts that read as one idea.

## Where it goes
`threads.md`, all threads in one file, separated by `---`.

## Shape
```
## Thread 1: working title
Angle: ...
1/ opening post that works alone and makes people tap in
2/ ...
...
N/ last post, with the one next step
```

## Rules
- Each post is 500 characters or fewer, usually 150 to 350. Check long ones.
- Post 1 is a hook with no "thread" or arrow emoji.
- One idea per post. White space between ideas. No hashtags.
- Posts should not all start the same way.
- The last post holds the next step in the exact wording from `brand/offer.md`.
- Never fabricate. If the teaching has no story, use plain teaching.
